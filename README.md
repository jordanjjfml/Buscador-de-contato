# 🔍 Buscador de Contato

Um aplicativo web simples e eficiente para **buscar e filtrar contatos** em uma lista de forma dinâmica. Este projeto foi desenvolvido com tecnologias web fundamentais (HTML, CSS e JavaScript) para praticar manipulação de arrays, eventos de input e filtros em tempo real.

## 🚀 Funcionalidades

* **Busca em Tempo Real:** Filtra os contatos instantaneamente conforme o usuário digita o nome ou telefone.
* **Interface Limpa:** Layout organizado para exibição clara das informações de contato.
* **Design Responsivo:** O buscador se adapta perfeitamente a telas de computadores e celulares.

## 📁 Estrutura do Projeto

O repositório contém os seguintes arquivos estruturais:

* `index.html` - Estrutura de marcação e campo de busca da página.
* `style.css` - Estilização visual, cores e alinhamento dos elementos.
* `script.js` - Lógica em JavaScript contendo a lista de dados e o filtro de busca dinâmico.

## 🛠️ Tecnologias Utilizadas

* **HTML5** – Estruturação e semântica da página.
* **CSS3** – Design, layout e responsividade.
* **JavaScript (ES6)** – Manipulação do DOM, funções de filtro (`filter`, `includes`) e interatividade.

## 💻 Como Executar o Projeto

Para testar o buscador localmente:

1. Clone o repositório em sua máquina:
   ```bash
   git clone https://github.com
   ```
2. Acesse a pasta do projeto.
3. Dê um duplo clique no arquivo `index.html` para abri-lo diretamente no seu navegador de preferência.
